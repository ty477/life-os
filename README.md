## 使用约定

1. 新的自我分析只追加 `docs/`，不覆盖旧文。旧文是证据，不是草稿。
2. 每周日在 `docs/weeklies/` 写一页，只写交付，不写心情总结。
3. 收藏可以继续，但新增必须能回答：这周要用，还是进博物馆。
4. GitHub README 的研究定位若和本周真实工作不一致，先改定位，再改自我感觉。
