# 水也很生情 / Tang Yi

2026-08-13。材料：小红书有效收藏 210 条（官方显示 466，打不开的按失效）、专辑 20 个、简介、GitHub 6 个公开仓库、年贡献约 15 次。没看见成绩单、聊天、未公开仓库，那些不编。

## 这个人在干什么

简介自己写了：Hall of Prime / Hall of Dark，人生博物馆，裂痕里进光。收藏结构跟这句话几乎同构。一边是正装、solo 出片、清华 PPT、ICML 对标、深圳 Citywalk、早睡协议；一边是鸟巢走不出来、组会痛苦、保研焦虑、生病教会我的事、如果一直停在那里。

对外身份更干净：自动化本科、嵌入式 AI、轴承故障诊断、航天 PHM、Q1。GitHub README 是一份求职/套磁用的研究名片。小红书是施工现场。两套东西目前对不上。

GitHub 上真实提交很少。SkyBrain 无人机平台是最大的可见项目（TypeScript 为主，Next.js + Three.js，5 star），最近一次业务提交停在 2025-10「准备生产部署」。城市风险平台、五子棋、另一个 SkyBrain 上传仓，大多是 2025-09 的 Add files via upload。2026-08-07 密集改了三版个人主页 README。主页比仓库新。

收藏里真正密的，不是轴承，是：27 届秋招 / Agent / 简历锐评、保研材料、Claude/Codex 科研工作流、早睡和手机脑雾、《挽救计划》专题、文慧心/鲁豫、旅行愿望单。故障诊断出现在名片上，几乎不出现在日常收藏里。

所以现在这个人更像：一个正在用 AI 工具给自己加速的 27 届学生，同时在保研叙事和求职叙事之间来回校准，审美很稳，作息协议写了很多遍，交付记录偏薄。

## 结构，不是性格标签

ENFJ 夹存在，但标签帮不了忙。能看见的是几股同时转的力。

**叙事欲很强。** 23 岁写回忆录、毕业四年写成一本、2026 新年献词、高考作文立意、梁祝即兴、「该用什么词来告别这一年」。你不是在收藏鸡汤，你在给自己找句能站住的话。Hall of Prime / Hall of Dark 也是叙事装置：先把人生设计成博物馆，再往里面填展品。

危险在于：博物馆可以替代工程。收藏一条「最高版本的自己」，晚上的自己并没有变得更高。GitHub 主页已经是展厅灯光，仓库还是 2025 秋天的样品。

**审美先于方法。** 消融模块要好看，正装要能撑场面，电影要情感浓度高，人物要温文有分寸（汪文斌），旅行要能出片，深圳要让朋友以为出国了。你讨厌先锋实验和 Amaze 式装神弄鬼，要「正常的作品」。这是一种很明确的品味：干净、电影感、克制的深情。

品味能帮你选导师气质、选项目呈现、选正装面试。品味不能写实验、不能回套磁、不能让 11 点真的睡着。

**工具崇拜接近宗教。** CCskills 里 Claude 读文献、Codex 出图、Nature Skills、html 输出教程、科研工作流 × AI Skill。你不是「了解一下 AI」，你在把 Agent/Skill 收成可复用外挂。这和 ZCode 能对上。也会滑向：收集工作流 = 已经会了。

**身体被当成系统漏洞反复打补丁。** 6:30 起 / 22 点睡 / 9 点睡你就是神 / 2026 早睡保命 / 手机脑雾 / 放下手机解决人生 / 防晒 / 不显老 / 喝水 / 养气血。同一条协议收藏了很多遍。收藏密度这么高，通常表示执行反复失败，不是已经练成。

**情绪需要专门的房间。** 蕾姆哭死、鼠鼠、奇思妙想、哈哈笑鼠。被接住的小矫情、母牛找小牛、海獭、川大回成都像回家。你允许自己软，而且软得具体。这不是弱点。弱点是软和冲共用一个抽屉（芝士），需要办事的时候会被哭湿。

**地理是真的生活线，不全是幻想。** 川/深、带父母游深圳、Citywalk、香港一日，和漠河极光、西沙、意大利、悉尼叠在一起。深圳像下一站或当前站，不是壁纸。父母出现在保研夹里，说明亲缘和路线已经缠在一起。

**人物投射很整齐。** 文慧心「想赢一定可以赢」、鲁豫的表达、汪文斌的沉淀、长生的忧郁帅、《挽救计划》里「没有我爱你但每一个选择都是你」。你要的成年样子：利落、会说话、有分寸、赢的时候不吵。这比 MBTI 准。

## 批评

1. **身份通胀。** README 写航天装备健康管理、Q1、边缘智能。公开仓库是无人机可视化平台、城市风险 Electron、五子棋。收藏主线是秋招简历和保研 PPT。三套语言同时成立，审稿人和面试官只会信你这周能讲清楚的那一套。现在最能讲清楚的，其实是「我会用 Claude/Codex 加速科研和材料」，不是「我已经在做航天 PHM」。

2. **收藏当完成。** 芝士 42 条官方计数，是杂物抽屉：早睡、防晒、套磁、组会、满分作文挤在一起。未进专辑还有 63 条有效笔记。102 条已经标了该挪到哪。你授权分流的那天，精神笔记建成了空夹，其余还没搬。计划本身又变成展品。

3. **GitHub 是橱窗不是工地。** 年贡献约 15。最近公开动作是给主页抛光，并给 SkyBrain 点赞。对保研/求职这是危险信号：主页越完整，仓库越经不起点进去。上传仓（Add files via upload）比提交历史更伤：看起来有项目，打开没有演化。

4. **两条人生楼梯一起爬。** 保研材料（清华 PPT、套磁都回了、保研难不难、保研焦虑）和 27 届秋招（学历厂、远程 AI 实习、Agent 项目、简历锐评）同时处于「本周行动」。两手准备没问题。两手都停在收藏层就有问题。你需要一个主楼梯，另一条标成备胎并给它截止日期。

5. **作息协议没有度量。** 「9 点睡你就是神」收藏第四遍的时候，问题已经不是不知道，是没人验收。没有睡眠记录、没有娱乐 App 卸载证据、没有连续 7 天 23:30 前放下手机的日志，这些笔记就是安慰剂。

6. **对标样本会吃人。** 本科二年级 ICML 一作、14 天 SCI、实习 AI PM 月薪过万。当样本，有用。当自我处刑工具，你会把正常的组会痛苦理解成人格失败。组会痛苦该进「科研日常」，不该进人生哲学。

7. **美把事情变重。** 你几乎不能忍受粗糙的中间态。论文图要有消融审美，旅行要出片，回忆录要按同人女出本。结果是：没开始，因为配不上博物馆。22 岁最贵的东西是可发表的丑草稿，不是完美展签。

8. **公共记忆和出片曾经混放。** 分流表里有「年度伟大发现」仍待定。沉重的和漂亮的如果继续混，博物馆会变成情绪垃圾场。你已经隐约知道这一点，否则不会自己做 Hall of Dark。

## 规训（从现在到半年）

不谈性格改造。谈约束。

**身份只留一句，写在周报第一行。**  
例如：「27 届，自动化，本周主攻：故障诊断小实验 / 保研套磁 / 秋招简历，三选一。」  
每周只能有一个主攻。另外两个最多各占 20% 时间。改主攻必须在周报里写原因，不许默默换。

**GitHub 工地化。**  
停掉新的上传式仓库。SkyBrain 要么补真实 README（去掉「你的用户名」这种模板句）、补一周内能跑的最小演示、写清你贡献了哪一层；要么降级为课程作业并在主页撤掉航天话术。  
个人主页加「This week I shipped」三行，没有交付就写「本周无交付」。空着比徽章诚实。

**收藏禁令。**  
本周行动清单锁 12 条，多一条先删旧的。新收藏必须选：本周要用 / 进博物馆 / 不存。芝士不再进新笔记。早睡类笔记禁止再藏，改成 14 天睡眠打卡；满 14 天才能再读一条相关笔记。

**身体验收。**  
连续 14 天：23:30 前屏幕离手，记录入睡点和次日是否 7 点前起来。失败不写检讨，只在周报记「破了 N 天」。破了就缩短娱乐窗口，不新开哲理专辑自我和解。

**材料截止。**  
保研：套磁信模板 + 个人介绍一页 + 三个导师名单，两周内出第一版，存在仓库 `docs/career/`，不存在小红书。  
求职：一份面向 AI/嵌入式实习的简历，用你收藏的锐评标准改三轮，第三轮必须给真人看。  
两份材料都没有的话，旅行愿望单冻结，穿搭收藏冻结。先有下一间房间的钥匙，再买房间的灯。

**写作从博物馆转到实验记录。**  
回忆录可以写，但每周先写 200 字「这周做了什么、卡在哪、下周验证什么」。文笔好不是豁免权。你已经会写「过程本身就是答案」——那就把过程写成可复查的句子。

## 监督怎么落到人身上

你需要的不是鼓励，是外部记忆。你自己的记忆你也承认差（「记忆惊人的差，与怀旧属性完全不匹配」）。所以监督系统必须写在仓库里，而不是写在简介里。

每周日对照 `protocol/weekly-review.md`。ZCode 按 `protocol/zcode-supervision.md` 跑。 cron 提示词在 `protocol/cron-prompts.md`。

验收只看四件事：

- 主攻有没有可打开的产物（仓库提交、PDF、可运行脚本、发出去的邮件）
- 睡眠 14 天窗口破了几天
- 收藏「本周行动」是不是仍 ≤ 12
- README 的研究定位和本周真实工作是否同一句话

四件里两件连续两周失败，下一周禁止新建任何「人生项目」（新专辑、新仓库、新博物馆厅）。只允许完成旧的。

## 对未来的判断（有证据的部分）

走得通的路，长得很窄：把「控制 + 嵌入式 + 一点深度学习」做成一个能演示的小系统（轴承、电机、采集板，任意一个真传感器），用 Claude/Codex 加速文献和出图，用正装和表达把故事讲完整。深圳或成电深研这条线，和你已经在收藏的生活动线是匹配的。

走不通的路，也清楚：同时做航天 PHM 叙事、低空经济平台叙事、保研清华叙事、Agent 实习叙事，靠收藏和主页维持四条。审稿周期和秋招时间表都会先到。

你的优势不是天赋神话，是两样已经存在的东西：审美判断稳定，以及愿意把自己做成档案。档案若只进小红书，你会变成一个很会生活的展厅讲解员。档案若进 GitHub 并且每周有 diff，你才是那个简介里要见的最高版本。

最高版本不会在一条笔记里出现。它会出现在连续 12 周都有产物、且睡眠记录难看但还在记的那个自己身上。
