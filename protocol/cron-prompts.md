# ZCode 定时任务提示词

在 ZCode 里建 cron 时直接用下面整段。不要让定时任务写新的人格分析。

## 每天 22:50（睡眠窗口）

标题：每天 22:50 睡眠窗口

```
读 C:\Users\DhYou\.zcode\workspace\default\life-os\protocol\weekly-review.md。
不要分析人格。只发三句：
1. 现在离开娱乐平台。
2. 问我：今晚能否 23:30 前离手？只准回答 能/不能。
3. 把日期和回答追加到最新的 docs/weeklies/ 里；没有本周文件就按 ISO 周号新建。
不要鼓励，不要列建议。
```

## 每天 9:30（三件实事）

标题：每天 9:30 三件实事

```
读 life-os 最新周报第一行主攻。
问我今天三件实事，每件必须能指向一个文件或一次提交。
我如果回情绪或计划，追问产物。
把三件事写入周报草稿「实际做了」。
主攻以外的事标成备胎，提醒我不要做。
```

## 每周日 21:00（复盘）

标题：每周日 21:00 周复盘

```
按 life-os/protocol/weekly-review.md 生成或补全本周文件。
先数：git 提交（排除纯 README 装修）、本周行动收藏是否超 12、睡眠破日。
四条验收中两条失败，在周报顶部写「禁止新建=是」，并列出下周不准做的事：新仓库、新专辑、新画像。
最后只留下周三件 120 分钟内能做完的事。
把文件写进 docs/weeklies/。
```

## 不要建的定时任务

- 每日一句鸡汤 / 最高版本提醒
- 每日小红书新收藏摘要（会喂成瘾）
- 每日改 GitHub 主页
