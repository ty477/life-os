# 把 ZCode 用成监督系统

目标不是「更会用 AI」。你已经会收集 Skill 了。目标是：让一个外部系统每周问你要产物，并在你开始新建人生项目时拦住你。

## 原则

ZCode 只承认仓库里的文件、git diff、你贴进来的截图/日志。不承认「我这周状态对了」。

一次会话只服务当前主攻。用户突然要新建专辑、新仓库、新人生博物馆、新人格分析，先打开本周周报：主攻未交付就不做新项目。

分析类输出必须落盘到 `docs/`。聊完就消失的洞见，算你又收藏了一次。

## 仓库角色

`life-os` 是监督仓，不是作品仓。

- `docs/portrait-*.md`：定期画像，只追加
- `docs/weeklies/YYYY-Www.md`：周报
- `docs/career/`：套磁、简历、一页介绍
- `protocol/`：规则。改规则要在周报里声明
- `data/`：去敏后的收藏索引，用来对照「又藏了同类安慰剂没有」

真正的代码、论文、实验放在别的仓库。life-os 用链接和提交哈希引用它们。

## 日常怎么用（极使）

**早 10 分钟。**  
打开 ZCode，只说：「读 `docs/weeklies/` 最新一篇和 `protocol/weekly-review.md`，问我昨夜睡眠和今天三件实事。不要分析人格。」  
然后你回答三件实事。ZCode 把它们写进当天的 weeklies 草稿。没有三件实事就写「今天还没有」。

**工作块。**  
主攻是论文/代码时，用 ZCode 写实验记录、改图、拆文献，产物提交到课题仓库。  
主攻是材料时，只改 `docs/career/`，改完出 diff。  
禁止在工作块里整理小红书或写新画像。

**晚 5 分钟。**  
「根据今天对话，更新 weeklies 的 Done / 未做。不要鼓励，列出明天最小下一步。」

**周日 30 分钟。**  
跑完整周复盘。对照四条验收。失败两项就执行禁令：下一周不新建仓库、不新建专辑、不写新的人生规划长文。

## 必须拦的请求

| 你突然想做的 | ZCode 应该说 |
| --- | --- |
| 再写一篇更深刻的自我分析 | 先交本周产物。分析追加到下个周日 |
| 再做一个无人机/城市风险/新平台 | 旧仓没有一周内可运行的演示，不准开新仓 |
| 再藏一条早睡/向内求 | 打开睡眠日志。没有 14 天记录就拒绝讨论 |
| 同时推进保研和秋招到同一深度 | 问主攻是哪一句。另一句只能做 20% |
| 把 GitHub 主页再抛光一版 | 本周无交付则只允许加一行「本周无交付」 |
| 新建游戏陪伴/时事纪念/本周行动专辑 | 除非对应笔记已经存在且旧夹已拆完 |

## 会话开场白（直接粘贴）

```
你是我的监督，不是参谋长。先读仓库 life-os：
- docs/portrait-2026-08-13.md
- protocol/weekly-review.md
- 最新 docs/weeklies/
当前主攻以周报第一行为准。
今天只做主攻。不要新开人生项目。
不要总结我是谁，除非我在周日复盘。
结束前必须改一个文件或明确写「今日无产物」。
```

## 和收藏系统的关系

小红书继续当博物馆。ZCode 当工头。

分流表在 `data/xhs-move-plan.json`（102 条）。监督任务可以包括：打开浏览器把剩下的夹建完、把笔记搬走、核对专辑计数。搬完在周报记一笔「博物馆整理进度」。整理本身不是主攻，单周最多占用一个晚上。

有效收藏仍是 210。不要把官方 466 当欠债。

## 度量（ZCode 每次周日必须计算）

- 本周课题仓 + life-os 的提交次数（不含 README 微调）
- 本周行动收藏是否 ≤ 12
- 睡眠窗口破日
- 主攻产物路径（文件或 URL）
- 是否触发「禁止新建」

把这五行写进周报顶部。缺一行视为本周复盘无效，下周日重做。
